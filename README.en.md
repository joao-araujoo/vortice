# Vórtice — Public Beta

Vórtice is a local-first Windows desktop development orchestrator. It keeps projects, Tasks, rounds, context packages, code backups, validation and approval history together, while leaving your editor, Git and ChatGPT as the tools they already are.

**Downloads:**
- [Windows Setup](https://github.com/joao-araujoo/vortice/releases/latest/download/Vortice-Setup.exe)
- [Portable ZIP](https://github.com/joao-araujoo/vortice/releases/latest/download/Vortice-Portable.zip)

See the full Portuguese README in [README.md](README.md).

The public build uses an assisted ChatGPT Web handoff. It does not ship browser automation that automatically extracts/downloads ChatGPT output.
